# Prompt -> App

Prompt -> App turns a natural-language idea into a researched, planned, tested and deployable application.

## Pipeline

Prompt -> adaptive research -> evidence-aware AI synthesis -> App Blueprint -> generation -> functional tests -> visual audit -> repair -> GitHub -> Vercel -> live URL.

The host agent can supply the existing LLM capability to synthesize the research corpus. No new provider key is required. If an LLM is unavailable, a deterministic fallback keeps the pipeline operational.

The blueprint forces research to become concrete decisions across core loop, onboarding, logging, schedules, progress, streaks, reminders, integrations, gamification, privacy, mobile UX and MVP scope.

Research claims from individual products are treated as evidence rather than universal truth. Explicit user requirements always take priority.

Generated applications never receive search, GitHub, Vercel, Composio, or model credentials.
